# Changelog

## 5.0.0 - 2026-10-18

- App-Installation auf generische Manifest-basierte Apps umgestellt.
- Launcher von app-spezifischen Annahmen bereinigt.
- App-Kontext auf generische Instanz-, Daten- und Konfigurationspfade reduziert.
- App-Katalog bleibt leer, solange keine installierbare App im Repository vorhanden ist.
- Privates Repository für AppConfig und AppData bleibt enthalten.
- Setup, Login, TOTP, Tenants, Benutzer, Gruppen, Rechte, Updates und Backups bleiben enthalten.

# Example Application

Diese Struktur ist ausschließlich eine Entwickler-Vorlage. Sie wird wegen `catalog.discoverable=false`, `installable=false` und `downloadable=false` weder im Launcher noch im App-Katalog angeboten.

Jede `.gitkeep` enthält die Namen der Dateien, die ein echtes App-Repository an dieser Stelle anlegen soll. Die Platzhalter selbst enthalten keinen Anwendungscode.
